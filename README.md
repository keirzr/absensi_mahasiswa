# Sistem Absensi Mahasiswa v1.0
Fakultas Informatika dan Komputer - Presensi Absensi

### Fitur:
- Login Akun Mahasiswa
- Register / Daftar Akun Mandiri via HP
- Dashboard Statistik Kehadiran Real-time
- Cari Data Mahasiswa Terdaftar
- Edit Profil Mandiri (Aman & Privat)
- Scan QR-Code Absensi menggunakan Kamera

### Tech Stack:
- PHP (Native)
- MySQL / phpMyAdmin
- Bootstrap 5 & FontAwesome
- HTML5-QRCode Scanner JS
- Ngrok (Untuk Online-kan Server Lokal)
